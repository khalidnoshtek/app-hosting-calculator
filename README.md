# Noshtek app hosting cost calculator

Estimates the monthly AWS hosting cost of each app on Noshtek's shared platform (AWS Mumbai, ap-south-1) and checks it against the client plans (Starter ₹1,999, Growth ₹3,499, Scale ₹8,999).

- Open `index.html` in a browser, or use the GitHub Pages link for this repo.
- Prices were checked on the official AWS, MSG91 and exchange-rate pages on 27 September 2026. The full list is on the page itself.
- Estimates, not quotes. Check real usage in AWS Cost Explorer.
